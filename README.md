# 📩 Subscribe Form

A simple and responsive **Subscribe Form** built using **HTML, CSS, and JavaScript**.

This project demonstrates a clean subscription form interface where users can enter their email address and interact with the form.

## 🌐 Live Demo

👉 **[Visit Subscribe Form](https://aryanh12345.github.io/Subscribe-Form/)**

## 🚀 Features

- 📧 Email input field
- 📩 Subscribe button
- ✅ Simple form interaction
- 🎨 Clean and modern design
- 📱 Responsive layout
- ⚡ Lightweight and fast
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Form structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Form interaction and validation
